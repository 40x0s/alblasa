# ورشة كسر الحماية — ميزان Pro

## الفريق: علي فيصل العطيفي · ماجد الدميني · المعتصم بالله الراعي

نظام محاسبة سعودي مبني بـ C#/.NET 6 (WPF) مع طبقة حماية تجريبية (Trial + Activation).
الهدف التعليمي: تحليل آليات الحماية البرمجية في تطبيقات .NET، وأساليب كسرها،
وكيفية تصميم حماية أقوى.

> ⚠️ هذا المشروع تعليمي لأغراض أكاديمية بحتة — لا يجوز استخدام هذه الأساليب
> على برمجيات لا تملك حق تحليلها.

## بيانات الدخول

- المدير:    `admin`      / `Admin@123`
- المحاسب:   `accountant` / `Acc@2024`

## خطوات الورشة المختصرة

1. شغّل `MizanPro.exe` وسجّل دخولك
2. افتح Procmon وراقب ما يكتبه في Registry
3. افتح dnSpy، ابحث عن النص `"غير صالح"`
4. تتبّع سلسلة الاستدعاء لـ `TokenProcessor.ParseAndVerify()`
5. عدّل الدالة لترجع `true` دائماً وشغّل النسخة المعدّلة
6. شغّل Python script لتوليد مفتاح صحيح حقيقي

التجارب التفصيلية خطوة بخطوة في ملف `LabSheet.md`.
